# Superhero Developer Documentation

Build applications and integrations for [Superhero](https://superhero.com), a social application
and community-token market on the æternity blockchain.

Use the REST API to read indexed data, call Sophia contracts to publish posts and trade tokens,
or use the agent tools to run these workflows from the command line.
