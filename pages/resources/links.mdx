# Official Links

Every official Superhero URL, shown as a literal string so you can compare it character by character
against whatever you were sent.

## The rule

> Superhero lives on `superhero.com` and `wallet.superhero.com`. Check for one of these two
> domains before you sign.

Check the domain before you sign anything. A phishing site can copy the interface (the palette,
the logo, the copy); the domain is what identifies the real one.

Superhero's own pages are on `superhero.com` and `wallet.superhero.com`. Treat a "Superhero" token
sale, airdrop, presale, migration or wallet-verification page on any other domain as phishing.

**Your key stays with you.** Support, migrations, verifications, airdrop claims and "wallet syncs"
never need it. Every legitimate Superhero action is a transaction you sign in your own wallet. See
[Security Best Practices](/wallets/security).
