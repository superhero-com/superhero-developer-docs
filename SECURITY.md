# Security policy

Thank you for helping keep Superhero safe. If you find a security problem in Superhero, its
contracts, its wallet, its API or these docs, report it privately rather than in a public issue
or pull request.

Use GitHub's **Report a vulnerability** button on the Security tab of the affected
`superhero-com` repository. Include what you found, how to reproduce it, and the impact you
expect. We will acknowledge the report and keep you updated until it is resolved.

Test against accounts and funds you own, and use testnet where you can.
