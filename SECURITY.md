# Security policy

Please do **not** open a public issue or pull request for a security problem in Superhero, its
contracts, its wallet, its API or these docs.

Report it privately through GitHub's **Report a vulnerability** button on the Security tab of
the affected `superhero-com` repository. Include what you found, how to reproduce it, and the
impact you expect. We will acknowledge the report and keep you updated until it is resolved.

Only test against accounts and funds you own, and use testnet where you can.
